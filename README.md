### 🔧 Git Skills Applied in This Repo

| Skill | How It Was Used |
|:------|:----------------|
| `git init` | Initialized the repository from scratch |
| `git add` / `git commit` | Staged and committed files incrementally across 14 commits |
| `git branch` | Created the `add_classics` feature branch |
| `git merge` | Merged branches — both locally and through pull requests |
| `git remote` | Connected to GitHub remote (`origin`) |
| `git push` / `git pull` | Synced local and remote repositories |
| `git log --graph` | Visualized branching and merge history |
| **Pull Requests** | Opened and merged PR #1 on GitHub |
| **Merge Conflicts** | Resolved conflicts when merging diverged branches |
| **Remote Collaboration** | Worked across local CLI and GitHub web interface |

```bash
# Clone the repository

# View the full commit graph
git log --all --oneline --graph

git branch -a

# Check the remote
git remote -v
```

### 🐧 Development Environment — WSL + Ubuntu

As part of this course, I set up and worked with **WSL (Windows Subsystem for Linux)** running **Ubuntu** on Windows. This included:

- Installing and configuring **WSL 2** on Windows
- Setting up an **Ubuntu** distribution as the development environment
- Running all Git commands through the **Linux terminal** inside WSL
- Managing the WSL environment (install, configure, and uninstall Ubuntu)
- Experiencing a real **Linux-based development workflow** on a Windows machine

> 💡 Working with WSL gave me hands-on experience with Linux — a critical skill for any backend developer.
